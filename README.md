# Islamic Books and Quran Text Collection

This folder contains a collection of Islamic books, educational materials, and Quran text resources for personal study and reference.

## Included files

### Quran text files
- `quran-simple.txt` — Arabic Quran text in a simplified plain-text format.
- `en.ahmedali.txt` — English translation of the Quran by Ahmed Ali.
- `en.transliteration.txt` — English transliteration of the Quran text.

### PDF books and study materials
The folder also includes a range of Islamic books and reference materials such as:
- Barahin-e-Ahmadiyya
- Essence
- Five-Volume Commentary
- Haqiqatul-Wahi
- Life of the Promised Messiah
- Philosophy of Teachings of Islam
- Salat and other prayer guides
- Tadhkirah
- Selected verses of the Quran
- And additional educational texts on Islamic belief and practice

## Purpose
This collection is intended for:
- Quran reading and study
- English translation comparison
- Transliteration practice
- Access to Islamic reference books in one location

## Notes
- These files are provided for personal study and educational use.
- Some material may be in PDF format and may require a PDF reader to open.
- For best results, use a text editor or viewer that supports UTF-8 Arabic text.

## Suggested usage
1. Open `quran-simple.txt` for the Arabic Quran text.
2. Compare with `en.ahmedali.txt` for English translation.
3. Use `en.transliteration.txt` for pronunciation guidance.
4. Refer to the PDF materials for deeper reading and explanation.

## Repository status
This workspace is a local study library and reference collection for Islamic learning.
